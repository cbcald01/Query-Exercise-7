# SQL Query Exercise 7

**CIS 310 | SQL**

## Project Overview
This exercise uses SQL queries to retrieve and filter customer and property management data. It includes comparing customer balances to average balances, calculating available credit, estimating service request costs, and filtering properties based on size and owner location.

## Features
- Uses subqueries to find customers with balances above the average.
- Calculates available credit from credit limits and customer balances.
- Filters records using conditions such as BETWEEN, LIKE, IN, and IS NOT NULL.
- Calculates estimated service request costs using hourly estimates.
- Retrieves properties by square footage and owner state.
- Sorts query results by balances, available credit, and estimated costs.
